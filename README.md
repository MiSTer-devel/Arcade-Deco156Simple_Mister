
# Deco156 simple compatible mister core

This is a mame derived core compatibile with:

- Joe and Mac Returns
- Osman / Cannon Dancer
- Chain reaction / Magical Drop / Magical Drop Plus
- Heavy Smash
- Charlie Ninja
- Party Time Gonta the diver 2

## Known issues

- Mosat of the games are missing 1 px of sprites at the start of the screen
- Heavy Smash has broken music and is in pre-release folder
