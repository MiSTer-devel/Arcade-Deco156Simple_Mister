# Arcade-Deco156Simple

Standalone MiSTer project exported from a JTCORES build.

Open Arcade-Deco156Simple.qpf in Quartus 17.0.2, or run `quartus_sh --flow compile Arcade-Deco156Simple`.
The sys/ folder is an unchanged Template_MiSTer snapshot (9c8eadb40067c8ce3aef90899844f62d688ac73a).
Core HDL, generated memory wrapper, macros, data and timing constraints come from the captured build.
Missing shared data supplements and platform-adapter changes are listed in export-info.txt and provenance/.
No JTCORES checkout or jtframe generation is needed to build.

This export changes the system framework: Quartus elaboration and timing, then hardware testing, are required before release.
Source mappings and file checksums are provided in export-map.tsv and export.sha256.

## Building this repository

The root project remains `Arcade-Deco156Simple`, matching the existing manual
GitHub Actions workflow. Open `Arcade-Deco156Simple.qpf` in Quartus 17.0.2 or run:

```sh
quartus_sh --flow compile Arcade-Deco156Simple
```

The build produces `output_files/Arcade-Deco156Simple.rbf`. The captured Osman
core includes its generated SDRAM wrapper and native EEPROM adapter; use the
MRAs generated by the matching JTCORES build for ROM and default EEPROM loading.
Game HDL resides in `rtl/osman/`, shared video in `rtl/cninja/`, and the captured
JTFRAME platform adapter in `rtl/emu.sv` and `rtl/jtframe/`. The older handwritten
wrapper, CRT adjustment additions and Python vendoring tool have been replaced.

The stock HPS adapter supports normal MiSTer input; the JTFRAME DB15 raw-read
extension is omitted. Four missing shared data files are supplied by the pinned
asset bundle: the font and FIR/OKI coefficient tables. Their provenance and
consumer-source checks are recorded in `provenance/` and `export-info.txt`.

The repository retains its existing project LICENSE. The original template
license is also retained in `provenance/Template_MiSTer.LICENSE`; source-file
copyright and license headers remain intact.

## Conversion validation

Quartus Prime Lite 17.0.2 analysis and elaboration passed for this exact
`Arcade-Deco156Simple` project on 2026-10-13. Stock `sys/` matches the pinned
Template_MiSTer snapshot byte for byte, and the captured Osman game/EEPROM
sources were checked unchanged. The private converter's Cninja and Osman
integration checks passed, including the relocated Amber include search path.

This check did not run full synthesis, fitting, timing analysis or hardware
validation. Use the manual CI Build workflow for the complete RBF compilation.

The three `deco56_*` HEX tables have one canonical copy at the project root.
Identical unused copies beside the Osman HDL were removed.

The source list is `Arcade-Deco156Simple.qip`, matching the QPF project name.
